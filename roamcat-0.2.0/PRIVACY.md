## What Data We Collect

RoamCat 只在你使用相应功能时处理下列数据。扩展不收集任何分析、遥测或崩溃统计数据。

1. **API Key（认证信息）**——当你选择「自备 API」模式时填写，保存在浏览器本机存储中，仅用于向你配置的服务端点发起请求。密钥以明文存储在你本机的浏览器配置中，其安全性依赖操作系统账户隔离——共享设备请使用独立的系统账户。
2. **网页内容**——生成帮助时必需的最小片段：目标词句、所选句子或段落、有限上下文（标题、所在章节与相邻正文，各有字符上限；自动预备的文章上下文最多 12,000 字符）。当你主动开启「整页双语翻译」时，处理范围覆盖页面上全部可见英文，包括正文与导航、侧栏、页眉页脚等页面构件中的文本（构件区域按规范化文本在本机去重，重复项不重复发送）。扩展不读取输入框、隐藏内容或视频字幕。
3. **阅读活动（可选，默认关闭）**——只有你明确开启「阅读记录」并添加允许的网站后，才在本机记录查询、标注、阅读时长与词数等事件；记录不含网页网址。无痕页面不采集。
4. **订阅账户显示信息**——使用本机订阅连接器时，设置页会显示你官方 CLI 登录态中的邮箱与套餐，仅用于展示连接状态。

## How Data Is Stored

- 全部数据仅存储在你的设备上：浏览器本机存储、会话存储与本地 IndexedDB。
- **不使用 `chrome.storage.sync`**，任何数据都不同步到服务器，也不随浏览器账户同步。
- 项目不运营任何中转服务器；你选择「订阅连接器」时，请求经由你自己电脑上的本机连接器与你自己的官方 CLI 登录态完成。

## How Data Is Used

- API Key 与网页内容：仅用于生成你请求的帮助（英文线索、局部中文说明、句子解构、整页双语翻译、文章摘要、领域识别）。
- 阅读活动：用于本机阅读记录与摘要；只有你进一步开启「个性化分析」时，才会把近 30 天内有限的查询、摘要与客观活动统计（不含网址、不含整篇正文）发送给你选择的服务，用于提出可逆的提示偏好调整。
- 诊断信息：仅记录去除正文与响应内容后的结构化元数据（操作类型、阶段、耗时、错误码、模型/服务的哈希指纹），可在设置中关闭、导出或清空。

## Third-Party Services

- 扩展本身不使用任何第三方分析、广告或统计服务。
- 只有在你主动配置或选择时，功能所需的文本才会发送给以下之一：**你自己填写并授权的模型服务商**（自备 API 模式），或**你自己官方 CLI 已登录的 ChatGPT / Grok / Google 订阅**（本机连接器模式）。这些服务由其各自的所有者运营，受其隐私政策与保留政策约束；请在授予前查阅所选服务的政策。
- 第三方名称与商标归各自所有者；提及仅为说明可复用的订阅权益，不代表关联或背书。

## Data Sharing

除上述「发送到你自己选择的服务以完成你所请求的生成」外，扩展不出售、不转售、不向任何第三方共享你的数据，也不将数据用于与核心功能无关的目的。

## Data Retention and Deletion

| 数据 | 保留 | 删除方式 |
|---|---|---|
| 设置与词档案 | 本机长期，直至你清理 | 设置 → 数据与隐私 → 清理 |
| 阅读记录 | 本机 90 天（超期按日聚合成归档统计） | 设置 → 阅读记录 / 数据与隐私 → 清理或导出 |
| 预备解释与译文缓存 | 仅当前浏览器会话（内存，译文缓存 5 分钟） | 关闭浏览器即清除 |
| 诊断记录 | 本机 7 天、最多 500 条 | 设置 → 运行诊断 → 清空 |
| API Key | 本机长期，直至你清除 | 设置 → 模型服务 → 清除密钥 / 删除服务 |
| 连接器诊断日志 | 你电脑上连接器数据目录内 7 天 | 设置 → 运行诊断 → 清空（下次连接同步） |

## User Controls

- 随时在设置中开启或关闭：阅读记录、阅读摘要、个性化分析、本机支持记忆、诊断记录、伴读猫。
- 随时导出或清理：支持数据（JSON）、阅读记录、诊断信息。
- 「记住求助词与支持偏好」关闭后，不再读取或更新个人词档案；原有档案保留至你清理为止。

## Changes to This Policy

如果数据实践发生变化，我们会更新本政策并同步「最后更新」日期；重大变更会随扩展版本说明告知。请以随扩展分发的最新版本为准。
