RoamCat 是什么？

RoamCat（随心阅）是免费开源的 Chrome / Edge 浏览器扩展，帮助中文读者阅读英文网站。一个引擎、两种模式：双语翻译按阅读位置在每段英文旁插入中文对照；阅读辅助保留整页英文，只给随你进步而渐退的稀疏提示。它还支持 PDF 与 EPUB 文件、YouTube 字幕和 Twitch 聊天。AI 来自你自己选的来源——33 家自备 API、本地 Ollama 模型，或你已有的 ChatGPT、Grok、Google 订阅——没有自有服务器，也不采集遥测。

两种模式，一个引擎

按页面、按心情选——共用同一套翻译与分析引擎。

🌐 双语翻译 · 主模式

页面英文原位译成中英对照，随阅读位置推进，不后台预译整篇。导航、表格、卡片原位对应；「返回英文」只移除扩展插入物，不回滚站点更新。

📖 阅读辅助 · 副模式

保留真实英文：难点词稀疏提示随读渐退；按住 D + 单击出查词卡片；划词选段按需救援；长难句画解构下划线，主谓宾一目了然。

🐱 伴读猫

趴在页边的 Shadow DOM 小伙伴——阅读开关、文章摘要、设置与快捷键入口；可拖拽贴边，每页一只，未启用时完全不注入。

📚 内置阅读器

打开 PDF / EPUB 文件或粘贴文章，共用同一套双语引擎——「翻译全文」按你的阅读位置逐段生成中文对照。

🎬 视频字幕与直播聊天

带字幕轨道的 YouTube 视频可显示双语字幕；没有字幕的视频可手动开启云端听写（经 Google 订阅连接器）；Twitch 直播聊天翻译需手动开启，默认关闭。

读懂真实网页

站点档案覆盖 GitHub、Reddit、Hacker News、Stack Exchange、Discourse、dev.to、Lobsters——代码区、diff、投票构件不进阅读块。

模型服务，自选来源

AI 能力来自你选的服务，而不是被绑定的厂商。

自备 API

33 家服务商、8 种协议——OpenAI、DeepSeek、Gemini、Anthropic、xAI、OpenRouter、Ollama、阿里云、火山、Kimi、阶跃等。结构化输出能力先探测后降级。

订阅连接器

本机 Native Messaging 复用官方 CLI 权益——Codex CLI（ChatGPT 订阅）、Grok CLI（SuperGrok / X Premium+）、Antigravity agy（Google AI Pro / Ultra），免 API Key。

本地模型

内置 Xenova/all-MiniLM-L6-v2 在离屏文档中做页面领域识别——全程离线，无需下载。

另提供 14 种机器翻译服务，整页、字幕、聊天、阅读器、选段可分别选引擎，失败可回退到大模型；Chrome 本机翻译不上传原文。接入说明。

全部 33 家服务商

OpenAI、Anthropic、Gemini、DeepSeek、Grok（xAI）、OpenRouter、Requesty、OpenCode、Command Code、MiniMax、SiliconFlow、Azure OpenAI、Amazon Bedrock、Groq、DeepInfra、Mistral AI、Together.ai、Cohere、Fireworks AI、Cerebras、Ollama、火山引擎（豆包）、阿里云百炼、月之暗面 Kimi、阶跃星辰、商汤日日新、智谱 GLM、小米 MiMo、腾讯混元 TokenHub、百度千帆、Hugging Face，以及自定义 Chat Completions / Responses 接口，共 8 种协议。想在自己的机器上跑模型，选 Ollama——无需 API Key。

本地优先的边界

  • 不经营服务器、不采集遥测；阅读记录默认关闭且按站授权；无痕页面不采集。
  • API Key 只存 chrome.storage.local——不进内容脚本、诊断日志或连接器。
  • 内容脚本仅可用 82 种消息中的 38 种白名单类型；模型输出全部经结构化校验才进入 UI。
  • 自定义 API 地址强制 HTTPS（仅本机回环允许 HTTP）；无远端代码执行。

常见问题

RoamCat（随心阅）是什么？

RoamCat（随心阅）是免费开源的 Chrome / Edge 浏览器扩展，帮助中文读者阅读英文网站。一个引擎、两种模式：双语翻译按阅读位置在每段英文旁插入中文对照；阅读辅助保留整页英文，只给随你进步而渐退的稀疏提示。本地优先，没有自有服务器、不采集遥测。

RoamCat 收费吗？

不收——MPL-2.0 开源，无账户、无付费档、无遥测。只有你自己选择接入付费 API 时才需要向该服务商付费；内置本地模型与订阅连接器本身不额外收费。

有没有沉浸式翻译的开源替代？

RoamCat 是其中一个：MPL-2.0 开源、自备模型（33 家 API、本地 Ollama，或复用已有的 ChatGPT / Grok / Google 订阅）、无遥测，并提供以英文原文为主的第二种模式。沉浸式翻译是平台更全、更省心的成熟整页翻译工具；其他开源选择还有 kiss-translator、openai-translator。

RoamCat 会把我的阅读数据传到哪里吗？

项目没有自有服务器。阅读记录默认关闭、按站授权；页面文本只在你主动调用模型功能时离开本机，且直达你配置的服务商，不经任何中转。

支持哪些浏览器？

桌面端 Chrome 与 Edge 125+（Manifest V3）。暂不支持 Firefox 与 Safari。

能在 Chrome 应用商店安装吗？

暂时不能。请从 GitHub Releases 下载安装包并解压，打开 chrome://extensions（或 edge://extensions），开启开发者模式，「加载已解压的扩展」选择里面的 extension 文件夹。Chrome Web Store 与 Edge Add-ons 上架进行中。

能整页翻译吗？

能——双语翻译模式按阅读位置逐段插入中文对照，并可一键切换「双语 / 仅译文」。阅读辅助模式则保持整页英文，只给随读渐退的稀疏提示。

支持 PDF 和 EPUB 吗？

支持——内置阅读器可打开本地 PDF / EPUB 或粘贴的文章，共用同一套双语引擎。

能翻译 YouTube 字幕或 Twitch 直播聊天吗？

能。带字幕轨道的 YouTube 视频可显示原文与中文译文；没有字幕的视频可手动开启云端听写（需另行安装本机 Google 订阅连接器）。Twitch 直播聊天翻译默认关闭，开启后只翻译新出现的公开聊天消息。

可以用哪些模型？

33 家自备 API、8 种协议——OpenAI、Anthropic、Gemini、DeepSeek、Grok、OpenRouter、Groq、Mistral、Ollama、Azure OpenAI、Amazon Bedrock、阿里云百炼、火山引擎、Kimi、阶跃星辰等，也支持自定义 OpenAI 兼容接口；另有内置本地模型做页面领域识别，或经本机连接器复用已登录的 ChatGPT / Grok / Antigravity CLI 订阅——免 API Key。

没有 API Key，能用 ChatGPT / Grok / Google 订阅吗？

可以，通过可选的本机连接器。它复用你已登录的官方 CLI——Codex CLI（ChatGPT）、Grok CLI（SuperGrok / X Premium+）、Antigravity agy（Google AI Pro / Ultra）——经 Native Messaging 与本机 127.0.0.1 服务连接。需要 Node.js 20+ 并已安装对应 CLI；费用、额度与地区可用性由各服务商决定。

能完全本地运行（Ollama）吗？

能。选择 Ollama 服务商（默认 http://localhost:11434），无需 API Key，页面文本只会发往你自己的 Ollama 服务。内置的 MiniLM 只在离线状态下做页面领域识别——翻译与解释始终需要你配置的模型服务。

RoamCat 申请哪些权限，为什么？

共 8 项 Chrome 权限——activeTab、scripting、storage、nativeMessaging、offscreen、contextMenus、tts、webNavigation——以及 http / https 站点访问（用于在你选择的任意网站上阅读与翻译）。内容脚本只能发送 82 种内部消息中的 38 种；API Key 不会进入内容脚本。隐私政策逐项列出了每项权限及理由。

怎么安装 RoamCat？

从 GitHub Releases 下载最新安装包并解压，打开 chrome://extensions，开启开发者模式，选择「加载已解压的扩展」并指向里面的 extension 文件夹；也可用 Node.js 22.13+ 从源码构建（npm ci、npm run build）后加载 dist/extension。

三步安装

构建

克隆仓库，运行 npm ci 与 npm run build（需要 Node.js 22.13+）；也可以跳过构建，直接从 Releases 下载免构建安装包。

加载

打开 chrome://extensions，开启开发者模式，「加载已解压的扩展」，选择 dist/extension 目录（Releases 安装包则选解压后里面的 extension 目录）。

开读

在任意英文页面点工具栏图标——或按 Alt+Shift+T 双语翻译。模型来源在「设置」里配置。
