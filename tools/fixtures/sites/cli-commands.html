Slash commands

Slash commands control the interactive session without leaving the prompt, and each one is documented with its accepted arguments below.

Docker Compose

CommandDescription
/settingsOpens the settings menu.
/setup [providers]
Alias: /providers		Opens provider setup for sign-in and web-search providers. No other subcommand is accepted.
/plan [prompt]Toggles plan mode; an inline prompt starts immediately. Requires plan.enabled, cannot be used in goal mode.
v2.3.1Prints the installed version and exits.
