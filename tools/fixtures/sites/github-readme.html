Visual Studio Code

Visual Studio Code is a lightweight but powerful source code editor which runs on your desktop and is available for Windows, macOS, and Linux distributions.

It comes with built in support for JavaScript, TypeScript, and Node.js, and has a rich ecosystem of extensions for other languages and runtimes.

The editor combines the simplicity of a text editor with the tooling features developers need for the core edit build debug cycle.
