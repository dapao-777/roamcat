This pull request adds the process report tool so that node can generate human readable diagnostic reports whenever a fatal error, signal, or explicit API call requires a snapshot of the runtime state.

The report helps support teams diagnose user problems in the field without asking them to reproduce a crash under a debugger, and it stays opt in so unaffected programs see no change in behaviour.
